`index.html` の掲載内容をファクトチェックします。

## 手順

1. まず自動チェックを走らせ、出典が確認できていない記述を洗い出す。

   !`python3 .claude/hooks/factcheck_scan.py report`

2. 引数（$ARGUMENTS）で対象が指定されていればその範囲に絞る。
   指定が無ければ、上のチェックで挙がったものに加えて、
   **改定されやすい項目**を優先して点検する。
   - `meyasu`（金額・基準のめやす）を持つ制度すべて
   - 電話番号・窓口名・担当課
   - 年度で変わる手当額、自己負担の上限額、貸付上限
   - `DATA_ASOF`（現在の掲載時点）より後に改定があった制度

3. 各項目について、CLAUDE.md「2. ファクトチェック手順」の優先順で
   一次情報を確認する。検索結果の要約ではなく、ページ本文の数字を見ること。

4. 結果に応じて処理する。
   - 一致 → `docs/fact-log.md` に追記（項目／値／出典URL／確認日）
   - 相違 → `index.html` を修正し、台帳にも追記。`DATA_ASOF` の更新要否も判断する
   - 確認できない → 本文に `【要確認】` を付ける。**推測で値を入れない**

5. 最後に必ず次の3つに分けて報告する。
   - ✅ 確認して正しかったもの（出典つき）
   - 🔧 誤りが見つかり修正したもの（旧値 → 新値、出典つき）
   - ⚠️ 確認できず `【要確認】` にしたもの

## 注意

- 一度に全44制度を確認しようとしない。範囲を区切り、確認できた分だけ台帳に残す。
- 「たぶん変わっていない」で済ませない。確認していない項目は⚠️に入れる。
